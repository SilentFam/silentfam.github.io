개인정보처리방침

최종 수정: 2026년 10월 30일

1. 수집하는 정보.

사이트는 회원가입, 로그인, 결제 기능이 없으며 이름, 이메일, 연락처 같은 개인정보를 직접 수집하지 않습니다.

2. 방문 통계.

사이트는 Cloudflare Web Analytics로 페이지 조회수, 방문 국가, 브라우저 종류 같은 집계 통계를 봅니다. 이 서비스는 쿠키를 쓰지 않고 방문자를 개별 추적하지 않습니다. 다만 서버 운영을 위해 IP 주소가 Cloudflare에서 처리될 수 있습니다.

3. 쿠키.

이 사이트는 추적 목적의 쿠키를 설정하지 않습니다.

4. 제3자 제공.

모은 통계를 팔거나 넘기지 않습니다. 호스팅과 통계 처리는 Cloudflare가 맡습니다.

5. 문의.
